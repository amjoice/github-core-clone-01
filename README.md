A GitHub-compatible git forge in Node 22 stdlib only — no dependencies, no git binary at runtime. It speaks the surfaces the `gh` CLI, `github-mcp-server`, and a real `git` client use: git smart HTTP (protocol v0 and v2, `ls-refs`, fetch, push), GitHub REST v3, GraphQL v4, and MCP.

## Run it

```sh
node --experimental-strip-types main.ts
```
